### Semantic Destruction via Paraphrasing
When semantic watermarks are deployed—often implemented via lexical substitution or synset-based probability shifting—they remain vulnerable to paraphrasing attacks, whether executed by humans or advanced Large Language Models. Paraphrasing alters the underlying syntax and vocabulary without degrading semantic integrity. Because lexical-substitution watermarks rely on specific token co-occurrence frequencies or biased sampling distributions, rewriting sentences neutralizes the embedded statistical signatures. Furthermore, neural paraphrase models trained to maximize perplexity relative to natural text distributions actively filter out unnatural token constraints. Concrete evaluation criteria for this vector encompass semantic similarity metrics (e.g., BERTScore) mapped against watermark detection accuracy (AUC-ROC), defining the Pareto frontier between robustness and text utility.

### Normalization Vectors and Unicode Exploits
Unicode normalization forms a critical vector for watermark degradation. Text data processed through standard normalization forms (NFC, NFD, NFKC, NFKD) often strips functionally redundant code points, canonicalizes diacritics, and replaces proprietary space characters with standard ASCII equivalents. Schemes utilizing homoglyphs or directional formatting codes (e.g., Right-to-Left Overrides) are neutralized by basic sanitization routines designed to prevent prompt injection and cross-site scripting. Evaluation of resilience against normalization requires measuring payload survival rates across strict UTF-8 parsing transformations, specifically tracking False Negative Rates under automated sanitization pipelines.
